AuraCD

PRIVACIDADE

Seus dados ficam no seu computador.

O AuraCD salva o acervo, as estatísticas de audição, configurações e capas no perfil local do Windows. Esses dados não são enviados a uma conta do AuraCD.

Para identificar discos e buscar informações, o aplicativo consulta serviços públicos de metadados pela internet. O contato técnico configurado para o MusicBrainz é usado apenas no cabeçalho solicitado por esse serviço.
